# ISAM ALAM Development
ALAM Software team covers the rover learning and thinking process, including sensing from LiDAR, cameras, and cobot 280 pi arm sensors. The full unit's goal is to take in sensory data, then learn from the environment and make the best choice on approaching regolith, harvesting, returning to base, go to manufacturing zone, or revert to power-safety mode. 
This is all WIP. Final deployment is expected around April/May
